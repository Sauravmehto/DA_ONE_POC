# 0009 — A free hosted demo (Netlify + Render)

**Status:** approved
**Touches:** deployment config only (`frontend/netlify.toml`, `render.yaml`); no application code

## Why

Nobody outside this machine can see the product. A throwaway hosted copy lets
people try it for a demo without paying for infrastructure.

## Not in scope

Production hosting (Redis sessions, multiple workers, durable storage). That
stays as `docker-compose.prod.yml` describes.

## The checklist

| | |
|---|---|
| **Reach** | Browser → Netlify (static build). `/api/*` is proxied by Netlify to Render, so the browser sees one origin. |
| **Permission** | Unchanged. `SIGNUP_MODE` stays at its default (invite); the first admin comes from `ADMIN_EMAILS` / `scripts/make_admin.py`. |
| **Failure** | Render's free tier sleeps after ~15 min idle (30–60 s cold start). Netlify proxy rewrites time out at ~26 s, so a slow warehouse query can fail through the proxy. Both are accepted for a demo. |
| **Isolation** | Single instance, single worker, `SESSION_BACKEND=memory`. Disk is ephemeral: `data/app.db`, `excel_storage/`, sessions and conversations are lost on restart or redeploy. Accounts must be recreated after a restart. |
| **The model** | Unchanged; `ANTHROPIC_API_KEY` is set in the Render dashboard. |
| **Cost** | Free tiers only. Anthropic and warehouse usage is billed to whoever owns those keys. |
| **Migration** | n/a, because nothing exists in an old place. |

## Behaviour

- **API** — Render runs `docker/backend.Dockerfile` (prod stage) with the start
  command overridden to one worker on `$PORT`. `/health` is the health check.
- **UI** — Netlify builds `frontend/` with pnpm and serves `dist/`, with an
  SPA fallback to `index.html`.
- **Secrets** — only in the Render dashboard (`sync: false` in `render.yaml`).
  `JWT_SECRET` is generated by Render. Use a read-only, demo-scoped warehouse
  user, not production credentials.

## Data

Nothing durable. See Isolation.

## Acceptance checks

1. `https://<render-host>/health` returns `{"status":"ok",...}`.
2. The Netlify site loads and `https://<site>/api/...` reaches the backend.
3. Sign-in persists across page reloads (cookie is `Secure`, first-party).
4. Replacing `RENDER_HOST` in `netlify.toml` is the only edit needed in the repo.
